# Task 1: The Silent Frontend Failure

A Next.js + Express app demonstrating how a UI can appear broken (stuck loading) while the real failure is hidden in the Network tab and backend logs.

## How to Run

### 1. Install & Start Server
Run the following commands:

```bash
npm install        # Install dependencies
npm run dev        # Start frontend (http://localhost:3000) & backend (http://localhost:4000)
```
